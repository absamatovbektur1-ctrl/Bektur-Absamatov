# Регистрация сервисов и ключи API

Эти шаги делаешь ты сам: нужна твоя почта, подтверждение и оплата. Ключи
никому не пересылай и в чат не вставляй, только в файл `.env`.

## 1. HikerAPI: поиск удачных рилсов конкурентов

1. Открой hikerapi.com и зарегистрируйся.
2. Пополни баланс на минимальную сумму. Один прогон по 18 авторам ≈ 72 запроса, это центы.
3. В личном кабинете скопируй **Access Key**.
4. Вставь в `.env`: `HIKER_API_KEY=...`

Проверка: `python3 radar/radar.py`

## 2. Metricool: публикация и статистика

1. Переведи Instagram в профессиональный аккаунт (Настройки → Тип аккаунта → Автор или Бизнес).
2. Зарегистрируйся на metricool.com и подключи Instagram.
3. Выбери тариф, где есть **API** (на бесплатном его нет; цену проверь на сайте).
4. Настройки → API: скопируй **токен** и **userId**.
5. **blogId**: открой свой аккаунт в Metricool и найди в адресной строке `blogId=ЧИСЛО`.
6. Вставь в `.env`:
   ```
   METRICOOL_USER_ID=...
   METRICOOL_BLOG_ID=...
   METRICOOL_API_TOKEN=...
   ```

Проверка: `python3 tracker/tracker.py`

## 3. Первый тест публикации

Сначала всегда черновик (без `--publish`):

```
python3 publisher/schedule.py story stories/test/frame_1.png --at 2026-11-01T19:00
```

Открой планировщик Metricool и убедись, что черновик появился с правильным типом
(сторис/рилс/карусель). Типы `REEL` и `STORY` в скрипте нужно подтвердить на этом
первом тесте; если Metricool вернёт ошибку типа, скажи Claude, он поправит.
