# Автоматизация Instagram @kisowss

Личный блог Бектура: молодым кыргызстанцам, которые думают «наверное, я не такой».
Стратегия, ICP, оффер и 20 идей: `strategy/strategy.md`.

## Цикл

```
radar (что уже сработало у других)
   → идеи и сценарии (strategy + брифы с 3 хуками)
   → создание: карусели, сторис, рилсы
   → publisher (Metricool, по расписанию)
   → tracker (статистика каждый день)
   → снова radar
```

| Модуль | Где | Что нужно |
|---|---|---|
| Стратегия | `strategy/strategy.md` | готово |
| Радар конкурентов | `radar/radar.py`, `radar/cohort.json` | `HIKER_API_KEY` |
| Карусели 1080x1350 | скилл `instagram-carousel` | фото, цвета бренда |
| Сторис 1080x1920 | скилл `story-sequences` | 15–30 своих фото |
| Монтаж рилсов | скилл `scripted-reels` | сырые дубли |
| Публикация | `publisher/schedule.py` | Metricool с API |
| Статистика | `tracker/tracker.py` | Metricool с API |

Исходные руководства: `docs/guides/`. Регистрация сервисов: `docs/setup-accounts.md`.

## Еженедельная рутина (≈1–2 часа)

1. **Радар** (понедельник): `python3 radar/radar.py` → открыть `radar/picklist.md`,
   посмотреть ссылки, отметить «да» в колонке Pick?. Попросить Claude:
   «напиши брифы для моих пиков» — 3 хука + сценарий + CTA на каждый.
2. **Съёмка**: записать рилсы по брифам (тело один раз, три хука).
3. **Карусели и сторис**: «сделай карусель по идее №3», «сделай сторис-серию про перчатки».
   Ритм сторис: 2 экспертные серии на 1 с призывом написать в директ.
4. **Публикация**: `python3 publisher/schedule.py ...` (сначала черновик, потом `--publish`).
5. **Статистика**: `python3 tracker/tracker.py` каждый день, вопросы Claude по `tracker/tracker.db`.

## Ключевые слова для CTA

Каждое слово используется только в одной активной кампании, иначе ответы в директе
не различить.

| Слово | Где | Что получает человек | Статус |
|---|---|---|---|
| ИДЕЯ | рилс №11 | разбор идеи и первый шаг на неделю | черновик |

## Правила

- Ключи только в `.env` (он в `.gitignore`).
- У конкурентов берём тему и структуру хука, но не их видео, звук и текст.
- Сначала черновик в Metricool, потом автопубликация.
- Ник в `radar/cohort.json` с пометкой «проверить» — первый запуск радара покажет, существует ли он.
