# Пост под тренд

Пользователь: Бектур, @kisowss. Общение и тексты на русском.
Стратегия, ICP и голос: `strategy/strategy.md`. Фото: `assets/photos/INDEX.md`.

## 1. Свежие тренды (каждый раз заново)

Тренды живут 1–3 недели. Сначала проверь `trends/` — если есть файл моложе 3 дней, используй его.
Иначе один поиск WebSearch (mode: extended) + 1–2 WebFetch:
- https://socialbee.com/blog/latest-instagram-trends/ (форматы, датированы)
- https://newengen.com/insights/instagram-trends/ (форматы + звуки)
- https://later.com/blog/instagram-reels-trends/
- звуки: https://creatordb.app/free-tools/trending-instagram-audio/

Брать только тренды **не старше 21 дня**. Сохранить выжимку в `trends/YYYY-MM-DD.md`:
название, дата, как выглядит, структура, звук, источник.

## 2. Фильтр под Бектура

Тренд подходит, если:
- его можно повернуть к теме ICP: «перестань думать, начни пробовать», «ты не один», вера и спокойствие;
- не нужно раскрывать бизнес-детали (Бектур не хочет рассказывать про проекты, деньги, Малайзию, перчатки, ферму);
- не нужно выдумывать события из его жизни — формулировать как общий опыт («ты», «мы») или брать из его слов;
- можно сделать из того, что есть: фото из `assets/photos/`, текст, код. Если нужно новое видео — сказать, что снять.

Не брать: тренды-шутки про семью/отношения, чужие лица, чужой контент, звуки с явными ограничениями для бизнес-аккаунтов.

## 3. Не повторяться

Прочитай `content/log.md`. Стиль/рендерер, использованный в последних 3 публикациях, не брать снова.
Бектур прямо сказал: «новый стиль, а то всё старое». Каждый пост — новый визуальный приём.

## 4. Выбор

Если пользователь сказал «делай» — выбери лучший тренд сам и делай.
Иначе коротко покажи 2–3 варианта (тренд → как повернём → что нужно от него) через AskUserQuestion.

## 5. Производство

Есть рендеры (переиспользуй, если стиль подходит и не повторяется):
| Рендер | Что делает |
|---|---|
| `carousels/notes_render.py` | Заметки iPhone, карусель или сторис (`"story": true`), фото, чек-листы, маркер `==...==` |
| `carousels/chat_render.py` | Переписка iMessage, сторис |
| `carousels/tweet_render.py` | Твиты, карусель |
| `carousels/warning_render.py` | Пародия «деликатный контент» |
| `reels/photodump.py` | Рилс из фото под бит с текстом |
| `reels/split_render.py` | Рилс «Да… но» / сплит-экран |
| `carousels/render.py` | Старый тёмный шаблон — не использовать (не понравился) |

Новый тренд без рендера → написать новый скрипт рядом с похожими (Pillow + ffmpeg, шрифт `carousels/assets/fonts/Inter.ttf`; если нет — скачать с `cdn.jsdelivr.net/gh/google/fonts@main/ofl/inter/Inter%5Bopsz,wght%5D.ttf`).
Конфиг — `config.json` в папке поста (`carousels/workspace/<slug>/` или `reels/<slug>/`).

Обязательно перед отправкой:
- посмотреть результат (контакт-лист через Read), лица не обрезаны, текст не налезает;
- нет номеров машин, документов, чужих личных данных;
- форматы: пост 1080x1350 (или 3:4), сторис/рилс 1080x1920, видео H.264 + faststart;
- текст в сторис/рилс — в безопасной зоне (не выше 200 px и не ниже 230 px от краёв).

## 6. Отдать

- файлы через SendUserFile;
- описание (голос из strategy.md: коротко, без хайп-слов, без эмодзи-спама);
- музыка: 2–3 трека из трендов недели + «если нет — ищи по запросу …»; предупредить, что наличие зависит от региона;
- куда и когда выложить (вечер 19–21 по Бишкеку), стикеры для сторис;
- ссылки на источники трендов.

## 7. Записать

Добавить строку в `content/log.md`: дата | формат | тренд | рендер | тема | папка.
Закоммитить конфиги и код (фото и PNG/MP4 не коммитить — репозиторий публичный).
