# Трендовые рилсы

Перед роликом: свежие тренды — по скиллу `trend-post` (шаг 1), журнал `content/log.md` — не повторять приём из последних 3 роликов.
Фото: `assets/photos/INDEX.md`. Шрифты: `carousels/assets/fonts/` (Inter, Lora). Видео собирать в `reels/<slug>/`.

## Правила, которые работают всегда

- **Первая секунда решает.** Движение или крупный текст-хук в кадре с 0-й секунды. Без «разгона».
- **Один смелый приём в первые 5 секунд**, не громоздить эффекты (источники: insideeditors.com, later.com).
- Ролик 7–15 с, вертикаль 1080x1920, 30 fps, H.264 `-crf 18 -pix_fmt yuv420p`, затем ремукс `-fflags +genpts+igndts -c copy -movflags +faststart` (убирает чёрный первый кадр).
- Текст — в безопасной зоне: не выше 220 px и не ниже 300 px от краёв (интерфейс Reels).
- Без звука при сборке: трендовый звук ставит Бектур в Instagram. Монтаж делать под темп 100–130 BPM (смена ~0,5 с).
- Субтитры/текст обязательны: большинство смотрит без звука.
- Конец = начало (петля) — повторные просмотры повышают охват.

## 20 приёмов (октябрь 2026) и как сделать здесь

| # | Приём | Рецепт |
|---|---|---|
| 1 | **Мультфильм / комикс из фото** (жирный контур, плоские цвета, полутон, баблы) | OpenCV: `bilateralFilter`×5 + k-means 8–12 цветов + `adaptiveThreshold` контуры; полутон точками в тенях; баблы Pillow. `reels/cartoon_render.py` |
| 2 | **Кинетический текст** — слова появляются по одному с «пружиной» | покадрово: scale = 1 + 0.25·e^(−8t)·cos(18t), альфа 0→1 за 4 кадра |
| 3 | **Склейки под бит** 0,4–0,7 с | concat с длительностями из списка битов |
| 4 | **Зум-удар (punch-in)** на акценте | масштаб 1→1.12 за 3 кадра, затем плавно назад |
| 5 | **Whip pan** (смаз-переход) | сдвиг кадра на 300–600 px за 4 кадра + `GaussianBlur` по горизонтали (`ImageFilter.BoxBlur` по X через resize) |
| 6 | **Match cut** | соседние кадры с одинаковой позой/формой (руки вверх → руки вверх) |
| 7 | **Переворот / reveal** «до → после» | поворот 0→180° или flip по Y за 6 кадров, на середине смена фото |
| 8 | **Сплит-экран «Да… но»** | `reels/split_render.py` |
| 9 | **Фото-дамп под бит** | `reels/photodump.py` |
| 10 | **Влог-таймстемпы** | в углу «07:40», «13:15» моноширинным шрифтом на каждом клипе |
| 11 | **Полоса загрузки** («Loading…») | прогресс-бар 0→100% поверх ролика, подпись этапа |
| 12 | **Фейковая переписка поверх видео** («Ты где?» — «Дома») | баблы iMessage из `carousels/chat_render.py` поверх кадра |
| 13 | **Скрапбук / рваная бумага** | фото в рамке-полароиде, скотч, бумага с рваным краем (маска шумом) |
| 14 | **Скомканная записка** | 3–4 стадии «разглаживания» (деформация сеткой) + рукописный текст (Caveat) |
| 15 | **Ken Burns + 2.5D параллакс** | медленный зум 1→1.08; для параллакса — вырезанный объект двигать быстрее фона |
| 16 | **Speed ramp** | для видео: `setpts=0.5*PTS` на кусок, `setpts=2*PTS` на акцент |
| 17 | **Вспышка / light leak** между сценами | 2 кадра белого с альфой 0.8→0 или тёплое пятно градиентом |
| 18 | **Плёнка / камкордер** | зерно `effect_noise`, тёплый тон, дата-штамп «31 10 2026» оранжевым |
| 19 | **Глитч / RGB-сдвиг** на 2–3 кадра | смещение каналов R и B на ±12 px |
| 20 | **Тряска камеры** на ударе («БАМ!») | случайный сдвиг ±18 px затухающий за 8 кадров + звёздочка-взрыв за текстом |

## Моушн-рилс из живых фото — ГЛАВНЫЙ движок (Бектуру нравится больше всего)

`python3 reels/motion_render.py reels/<slug>` — реальные фото, без стилизации, сила в движении:
переходы `whip` (смаз, dir left/right/up/down), `zoom` (пролёт), `flip` (3D-переворот), `page` (перелистывание страницы),
`swipe` (карточка улетает), `spin` (вращение), `drop` (фото падает полароидом поверх, стопка), `cut` (удар зумом);
медленный наезд камеры на каждом кадре, кинетический текст по словам с пружиной.
Кадр 0,9–1 с, первый и последний — 1,5–2,2 с; чередовать переходы, не повторять один подряд.

## Отклонено Бектуром — не предлагать

- Мультфильм/комикс (`reels/cartoon_render.py`) — «не понравилось, не мультяшный».
- Тёмный шаблон карусели (`carousels/render.py`) — «дешёвый дизайн».

## Мультфильм-рилс (движок есть, но стиль отклонён)

`python3 reels/cartoon_render.py reels/<slug>` — сцены из `config.json`:
фото → мультяшный вид → Ken Burns → плашка-рассказчик (жёлтая, как в комиксах) → бабл с «пружиной» → переходы (вспышка, тряска на `"bam"`).
Лица другим людям не показывать без согласия; номера машин — нет.
